# 标定校准指南

## 概述

每个硬件环境（摄像头位置、机械臂安装角度）不同，首次使用需要标定。

## 1. 摄像头棋盘四角标定

### 工具

使用 `tools/roi_selector.py` 或 `tools/click_calibrate.py`。

### 步骤

1. 将棋盘放在固定位置，确保无遮挡
2. 运行调试工具，点击棋盘四个角点（左上→右上→左下→右下）
3. 记录四个点的像素坐标
4. 更新 `chess_engine/config.py` 中的 `FIXED_PTS`：

```python
FIXED_PTS = np.float32([
    [310, 102],   # 左上
    [931, 95],    # 右上
    [279, 679],   # 左下
    [983, 664]    # 右下
])
```

5. 更新网格边界参数 `GRID_LT`, `GRID_RT`, `GRID_LB`, `GRID_RB`

### 验证

运行视觉模块，观察 "Warped View" 窗口中网格线是否对齐实际棋盘。

## 2. 霍夫圆参数调节

### 工具

运行主程序后，使用 "Hough Controls" 窗口实时调节参数：

- **param1**：Canny 边缘检测高阈值（默认 49）
- **param2**：圆心检测累加器阈值（默认 22）— **增大减少误检，减小增加检出率**
- **minDist**：圆心间最小距离（默认 32）
- **minRadius/maxRadius**：圆半径范围（默认 15-25）

### 目标

- 所有棋子都被绿圈标出且被分类
- 无"空气棋子"（将非棋子区域检测为圆）

## 3. 机械臂标定

### 工具

`robot_arm/calibration/` 下的脚本。

### 步骤

1. **XY 打点**：运行 `xy_calibration.py`，机械臂依次移动到棋盘上已知位置
2. **像素映射**：运行 `camera_matrix.py`，记录每个位置对应的像素坐标
3. 生成 TPS 映射模型 `calibration_data/map_model.npz`

### 验证

发送测试移动指令，确认机械臂能准确到达指定像素位置。

## 4. 废棋区配置

在 `chess_engine/config.py` 或视觉模块中配置两个废棋区 ROI：
- 人类废棋区（棋盘左侧）
- 机器人废棋区（棋盘右侧）
