# TCP 通信协议

## 概述

各模块通过 TCP (localhost:8888) 与 Qt 服务端通信。协议为纯文本，每条消息以 `\n` 结尾。

## 注册

模块启动后首先发送注册消息：

```
REGISTER:模块名
```

支持的模块名：
- `象棋引擎` — chess_engine/
- `控制系统` — robot_arm/
- `语音播报` — voice/
- `五子棋引擎` — gomoku/

## 消息格式

### 服务端 → 引擎

| 消息 | 格式 | 说明 |
|------|------|------|
| 开始对弈 | `开始对弈{难度}` | 难度 1-4 |
| 残局对弈 | `残局对弈{难度}:{名称}` | 如 `残局对弈1:大鹏展翅` |
| 一键摆盘 | `一键摆盘` / `一键摆盘红` | 自动摆放开局 |
| 玩家落子完成 | `玩家落子完成` | 人类确认走棋 |
| 悔棋 | `悔棋` | 撤销两步 |
| 替我思考 | `替我思考` | 引擎替人类走棋 |
| 退出 | `退出` | 终止程序 |

### 引擎 → 服务端

| 消息 | 格式 | 说明 |
|------|------|------|
| 准备完毕 | `准备完毕` | 引擎初始化完成 |
| 文字播报 | `文字:播报内容` | 触发语音播报 |
| 请玩家落子 | `请玩家落子` | 轮到人类走棋 |
| 走法无效 | `走法无效:请重新落子` | 非法走法 |
| 走法非法 | `走法非法:请重新落子` | 合规校验失败 |
| 人类获胜 | `人类获胜` | 游戏结束 |
| 机器人获胜 | `机器人获胜` | 游戏结束 |

### 引擎 → 机械臂

| 消息 | 格式 | 说明 |
|------|------|------|
| 棋子移动 | `棋子移动:(x1,y1),(x2,y2)` | 从(x1,y1)抓取移动到(x2,y2) |

### 机械臂 → 引擎

| 消息 | 格式 | 说明 |
|------|------|------|
| 运动完成 | `运动完成` | 所有电机到位 |

## 通信时序

### 人类执红先走

```
Qt服务端         象棋引擎          机械臂           玩家
   │                │                │               │
   │──开始对弈1───►│                │               │
   │                │──请玩家落子────│──────────────►│
   │                │                │               │ (人类走棋)
   │◄─玩家落子完成──│◄───────────────│◄──────────────│
   │                │ (识别+校验走法) │               │
   │                │ (引擎计算)      │               │
   │                │──棋子移动──────►│               │
   │                │◄─运动完成───────│               │
   │                │──文字:将军─────►│               │ (语音播报)
   │                │──请玩家落子────│──────────────►│
   ...              ...              ...             ...
```
